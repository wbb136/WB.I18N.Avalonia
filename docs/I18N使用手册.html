WB.I18N.Avalonia 使用手册

接入项目

安装本地 NuGet 包

把 WB.I18N.Avalonia.2.3.0.nupkg 放到解决方案的 packages 目录，并在解决方案根目录的 NuGet.Config 中加入本地源。项目已配置 packageSourceMapping 时，把 WB.I18N.Avalonia 映射到该源。

在声明 partial class I18N 的项目里添加引用。离线还原时，Avalonia 及它的依赖需已在 NuGet 缓存内，或可从本地源取得。 .NET CLI 包引用说明

把分部类和资源放在同一个项目

假设资源项目的根命名空间是 Demo.Localization，添加 Resources/Language.resx 和 Resources/Language.en.resx。前者存默认中文，后者存英文，两份文件共用键名。将生成操作设为「嵌入的资源」，特性填写默认资源的清单名称，省略后缀。

构建时，源生成器补全 GetString、Format 和 Current，并从中性 .resx 生成同命名空间的 I18NKeys 常量类。应用和业务模块引用资源项目即可使用。

分部类放在独立类库时，应用可在构建窗口前访问 I18N.Current，例如从设置恢复 LanguageTag，让资源类库在页面首次取值前加载。业务代码通过这一共享入口取值，普通 .cs 文件各自无需配一份 .resx。

ServoWeld 采用字符串写法 [I18NResource("LanguageAsset.Resources.Language")]。LanguageAsset 中的语言文件以嵌入资源参与编译，直接提供默认资源的清单名即可。

已有强类型资源类时，可选用 typeof

从 2.1.0 起，如果 Language.resx 已配有 Language.Designer.cs 等强类型资源类，可以传入这个类型。包用类型所在的程序集及类型全名查找中性资源。例如 Demo.Localization.Resources.Language 对应 Demo.Localization.Resources.Language.resources。

调用方可以自行选择。只有 .resx 时，使用字符串即可，资源文件的「自定义工具」可以留空。已有资源类时也可以选择字符串。类型在另一程序集时，该类型需要对声明 I18N 的项目可见。

分部类和资源位于不同程序集

已有类型的全名与资源名不同时，使用 typeof(类型) 指定程序集，再传入完整的资源名。以下示例的资源位于 SharedTexts，清单名应与该项目的根命名空间及资源路径对应。

如果中性 .resx 位于另一个项目，可以将它列为声明 I18N 的项目的 AdditionalFiles，并指定资源清单名及程序集名称。

三种声明选一种即可。同一程序集只声明一个带 I18NResource 的分部类。包的 CLR 命名空间为 WB.I18N.Avalonia，调用方可以把分部类放在自己的命名空间。

C# 后台取值与格式化

ViewModel、服务和窗口后台代码先引用声明 I18N 的资源项目，再导入该类的命名空间。ServoWeld 使用 using LanguageAsset;，本手册的新项目示例使用 using Demo.Localization;。这些入口由源生成器提供。

调用用途
I18N.GetString(string? resourceKey, string? fallback = null)用固定键或变量键读取当前语言的文案，可传备用文案。
I18N.Format(string resourceKey, params object?[]? arguments)用资源里的模板格式化参数，返回字符串。
I18N.Current.LanguageTag读取或切换应用语言，接受 .NET 支持的区域性名称，例如 zh、ja、fr-CA。

按固定键或变量键取值

已知资源键可以使用 I18NKeys.ProductTeach 等常量。包含特殊字符的键会转换为有效的 C# 标识符，同名时生成可区分的成员，常量值保留原始键。对于运行时取得的键，可以传入字符串变量。查找顺序是当前语言、父级语言、默认资源、调用时传入的备用文案、键名。传入 null、空字符串或纯空白时，返回备用文案，未提供时返回空字符串。

按语言模板格式化参数

{0} 对应第一个参数，{1:N0} 对应第二个参数，并以当前语言的数字规则保留零位小数。数字和日期可以直接传值，例如 int、decimal 和 DateTime。即使模板来自父级语言或默认资源，参数仍按 LanguageTag 指定的区域性格式化。修改此属性也不会改变当前线程的区域性。译文可以按语序调整占位符位置，参数索引保留原含义。要在模板里显示字面大括号，可写 {{ 和 }}。

省略参数或传入空数组时，Format 原样返回模板。传入参数后，如果模板语法错误、索引超出参数范围，或参数格式不匹配，C# 和 AXAML 格式化都会返回已查到的原始模板。各语言资源中的占位符都应与调用方传参一致。

切换语言后重新取值

GetString 和 Format 返回调用当时的字符串。弹窗或提示在显示时重新取值即可。如果 ViewModel 缓存了界面文案，可以订阅 I18N.Current.PropertyChanged，在收到 LanguageTag 通知时重新取值并通知界面，在对象退出时解除订阅。切换应用语言应在界面线程进行。

应用完全没有声明语言资源时，可以调用运行时的 I18NExtension.GetString(key, fallback) 取得备用文案、键名或空字符串。已引用资源项目的业务代码统一通过生成的 I18N 类调用。

在 AXAML 中绑定

通过 x:Static 使用固定键

页面使用 Avalonia 默认 XML 命名空间时可直接写 {I18N ...}。包通过 XmlnsDefinition 将 CLR 命名空间 WB.I18N.Avalonia 映射到 Avalonia 默认命名空间。需要显式前缀时，可声明 xmlns:i18n="clr-namespace:WB.I18N.Avalonia;assembly=WB.I18N.Avalonia"。 Avalonia XAML 命名空间

给 Key 和格式化参数绑定数据

把页面的 DataContext 设为下面的 ViewModel。启用了编译绑定的项目需声明相应的 x:DataType。更新键或参数属性后发出 PropertyChanged，页面会重新查找或格式化。

普通字段或局部变量的赋值没有绑定通知。需要持续更新时，使用能发出通知的属性，例如 INotifyPropertyChanged 或 CommunityToolkit.Mvvm 的 ObservableObject。事件由界面线程上的交互或调度回调触发。

添加和切换语言

设置界面语言

库首次初始化时采用宿主的 CultureInfo.CurrentUICulture。宿主使用不变文化或无法取得对应文化时，LanguageTag 为空，直接读取默认 .resx，数字和日期采用不变文化格式。应用需要固定启动语言时，可在创建界面前显式设置语言，例如 zh。在界面线程执行 I18N.Current.LanguageTag = "fr-CA"; 后，C# 取值和 AXAML 绑定都会从加拿大法语开始查找译文。宿主日后更改线程文化时，需要通过 LanguageTag 显式切换库内语言。

设置时会去除首尾空白，并采用 .NET 返回的规范名称，例如 " FR-ca " 会变成 "fr-CA"。空白或 .NET 拒绝的名称会保留当前设置。重复设置同一规范名称时，不会再次发出语言变更通知。

添加译文资源

  1. 在默认 Language.resx 的同一目录加入 Language.fr.resx 或 Language.fr-CA.resx，生成操作设为「嵌入的资源」。
  2. 沿用默认资源中的键名和格式化参数索引。只需填写本语言要覆盖的译文。
  3. 重新构建或发布。应用会按 fr-CA、fr、默认 Language.resx 的顺序查找加拿大法语缺少的条目。

ServoWeld 的「显示」页保留默认中文，并根据发布目录中的 LanguageAsset 语言卫星程序集生成可选项。新增译文随发布产物部署后，语言会以其本地名称出现在下拉框，无需改动 C# 语言列表。C# 仍可直接设置未部署译文的有效名称，取值会按上述顺序回退。

WB.Controls.Avalonia 的内建文案有中英文两套。ServoWeld 对 en、en-US 等英语区域性选用英文内建文案，其余区域性使用中文内建文案。应用自己的译文独立使用 LanguageAsset。

构建和发布

按应用现有方式执行 dotnet publish。默认资源随所属程序集编译，各语言译文发布到对应区域性命名的子目录，例如 en、fr 或 fr-CA。分发完整发布目录，保留这些子目录和卫星程序集。 .NET 资源打包与部署

运行时和源生成器来自同一个 NuGet 包，应用的语言文件分别由资源项目编译。源生成器由编译器从包的 analyzers 目录加载。

常见排查

问题检查位置
找不到 GetString 或 Current在声明分部类的项目里安装 NuGet 包并重建。类需为顶层、非泛型的 static partial class。检查 WBI18N001 至 WBI18N004 的编译诊断。
typeof 提示找不到资源类型检查项目是否已有可访问的强类型资源类。只有 .resx 时直接使用字符串写法。单参数 typeof 需要 2.1.0 及以上，类型全名应与中性资源清单名匹配。
编译提示 CS0542资源文件的自定义工具设为空。若 Language.Designer.cs 由强类型生成器生成了同名成员，恢复由 I18N 读取嵌入资源的方式。
页面显示键名或备用文案检查键的大小写、资源的嵌入方式、特性里的清单名。资源在类库时，确认应用已引用并加载该类库。
换键或参数后仍是旧文案确认页面正确绑定 DataContext 和属性路径，且赋值时对对应属性发出 PropertyChanged。
发布后缺少新语言选项或仍显示默认文案检查发布目录中是否保留对应区域性的卫星程序集，以及选中的区域性名称和需要翻译的资源键。
界面显示原始格式模板逐个检查各语言的占位符、数字格式和参数个数。各语言可按语序调整占位符位置。
